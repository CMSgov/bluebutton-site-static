## Framework 

## **Framework**

You agree to use the Blue Button API in a manner consistent with this framework, unless the law says otherwise or as specified above:

* **Transparency**: Record-keeping systems and databanks with enrollee data should be publicly known. Also, there should be a clear description of the main purposes and uses of the data.  
* **Consent**: Personal data collection should be done legally and fairly. When appropriate, the data should be gathered with the knowledge or consent of the individual. Personal data can’t be shared with third parties without the enrollee’s consent unless allowed by law.  
* **Use and Disclosure**: There must be limits on how personal data is used internally. The data should only be used for the reasons stated at the time of collection. Personal data can’t be shared outside without the enrollee’s consent or as otherwise allowed by the law.  
* **Individual Access**: Each enrollee should have the right to view any data about themselves and to annotate any data that is not timely, accurate, relevant, or complete, where the application can do so.  
* **Security**: Personal data needs strong protection. It should protect against risks such as loss, unauthorized access, destruction, use, modification, or disclosure.  
* **Data Quality**: Personal data should be relevant to its intended use. It should also be accurate, complete, and timely.  
* **Accountability**: Record keepers should be accountable for complying with fair information practices.
